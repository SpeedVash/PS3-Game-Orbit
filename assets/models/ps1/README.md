# Caixa PS1 — prévia editável

Preparação do modelo `effe_compact_disc_and_case.blend` fornecido no anexo, de **effe**, sob CC0. A licença original acompanha esta pasta. O arquivo Blender contém a cena de estúdio; o GLB contém apenas o modelo, suas texturas e a animação `PS1_AbrirEFechar`.

A tampa e o livreto abrem pela dobradiça. O disco sai do encaixe e desliza para fora. O CD foi reconstruído com anéis circulares; as demais peças vêm do modelo fornecido, com redução de detalhe. A arte é demonstrativa, criada para esta prévia com Noto Sans (OFL).

O modelo ainda não integra o renderer RSX nem o instalador de PS3. Veja [a preparação e a prévia](../../../docs/PS1_MODELO_PREVIEW.md).
