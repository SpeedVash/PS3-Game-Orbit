# Modelo Blu-ray JFX

Os arquivos 3D editáveis são obtidos diretamente do autor:

https://www.turbosquid.com/3d-models/free-dvd-bluray-case-3d-model/724523

Baixe JFX_DVDBlu.zip e execute na raiz do projeto:

```bash
python3 scripts/prepare-jfx.py --source /caminho/JFX_DVDBlu.zip
```

Arquivo usado: `BlurayCase/Models/Bluray_Tris.obj`.

SHA-256 esperado: `4263705eb3e9801ee10d173094865fb50c5b52dfd52d2f1160390a09e3034c55`.

O OBJ, templates PSD e malha convertida não devem ser publicados com o repositório. Consulte `CREDITS.md` e `docs/BUILD.md`. A versão instalável já inclui a geometria compilada ao aplicativo.
